ルート評価基準について

「ノー遅延乗り換え」が提示する4つの評価軸（スコア）の算出方法を解説します。

当サービスでは、単なる「所要時間」だけでなく、快適さや遅延リスク、コストを含めた多角的な視点でルートを評価し、5段階のスコア（5.0点満点）で表示しています。

🚀

速さ (Speed)

検索された候補の中で、最も所要時間が短いルートを基準（5.0点）として相対的に評価します。

算出式

スコア = 5.0 × ( 最短所要時間 ÷ このルートの所要時間 )

例：最短ルートが30分で到着する場合、所要時間60分のルートは
5.0 × (30 ÷ 60) = 2.5点 となります。

5.0点 最速のルート
🌱

快適 (Comfort)

駅の1日平均乗降客数データを基に、空いているルートほど高得点となります。

算出基準

  • • 乗降客数 3万人以下： 5.0点 (最高)
  • • 乗降客数 60万人以上： 1.0点 (最低)

※ 複数の候補がある場合、偏差値を用いて相対的にスコアを調整（補正）しています。人が少ないマイナーなルートほど高評価になります。

5.0点 閑散とした駅・路線（座れる可能性大）
🛡️

安定 (Reliability)

過去の遅延発生率を減点方式で反映します。現在のリアルタイム運行情報も考慮されます。

算出式

スコア = 5.0 - ( 最大遅延発生率[%] )

例：経由する路線のうち、最も遅延が多い路線の遅延率が 2.0% の場合
5.0 - 2.0 = 3.0点 となります。
※ 現在現実に遅延が発生している場合は、強制的に低スコアになります。

  • 5.0点 遅延率 0% (ほぼ遅延なし)
  • 3.0点 遅延率 2% (50回に1回程度遅延)
💰

安さ (Cost)

候補の中で最も運賃が安いルートを基準（5.0点）として相対的に評価します。

算出式

スコア = 5.0 × ( 最安運賃 ÷ このルートの運賃 )

例：最安ルートが500円の場合、運賃1000円のルートは
5.0 × (500 ÷ 1000) = 2.5点 となります。

5.0点 最安のルート
