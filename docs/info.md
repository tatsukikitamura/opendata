# 応募作品情報

## 応募作品名
ノー遅延乗り換え - 遅延リスクを避けるルート検索

## 応募作品を公開しているURL
https://opendata.tatsuki.dev/

## 作品の説明
「ノー遅延乗り換え」は、過去の運行データから未来の遅延リスクを予測し、提示する乗換案内アプリケーションです。
既存のサービスは「現在」の遅延情報しか提供しませんが、本作品は独自の遅延予測エンジンにより、現在は平常運行していても到着時に遅延する確率が高いルートを事前に警告します。また、生成AIを活用した「AIコンシェルジュ」が、数値だけでは判断しにくい定性的なアドバイス（例：「荷物が多い時は混雑するこの駅を避けるべき」等）を提供し、ユーザーの意思決定を支援します。さらに、速さ・快適・安定・安さの4軸でルートを評価するスコアリング機能を搭載し、ユーザーの状況に合わせた最適な移動手段を提案します。「いかに速く着くか」だけでなく「いかに確実に着くか」を追求し、遅延によるストレスや損失を未然に防ぐことを目指しています。
